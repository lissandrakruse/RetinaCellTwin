# RetinaCellTwin v0.3.0

This release freezes the expanded, open RetinaCellTwin research package for
archiving and DOI registration.

## Scientific additions

- Five-study NASA OSDR evidence base: OSD-203, OSD-255, OSD-557, OSD-568 and OSD-758.
- Prespecified transfer test of a 362-gene RR-9 discovery panel.
- Artificial-gravity and time-resolved ground-analogue audits.
- Sample-level VST and independently normalized STAR-count effect audits.
- Versioned Gene Ontology enrichment and Mouse Retina Cell Atlas anchor context.
- Explicitly unpaired cross-modal evidence matrix covering photoreceptor,
  apoptosis, oxidative-stress and vascular/barrier domains.
- Six deterministic publication figures and a GigaScience-formatted DOCX draft.

## Reproducibility additions

- Exact Python dependency lock, Conda environment and Dockerfile.
- Single-command `run_all.sh` workflow.
- Continuous-integration release tests and SHA-256 input provenance.
- Frozen machine-readable result tables and manuscript source.

## Interpretation boundary

The release does not support a stable universal retinal gravity signature.
The seven-day radiation-compatible signal is transient and hypothesis-generating,
not causal. Cross-modal convergence is descriptive and study-level because the
RNA-seq and imaging observations are not accession-matched or sample-paired.
RetinaCellTwin is not a clinical predictor or a validated individual-level
physiological digital twin.
