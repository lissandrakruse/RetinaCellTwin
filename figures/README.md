# Publication figures

All figures are deterministic SVG files generated by `python analysis/make_figures.py` from frozen result files.

1. `figure1_evidence_architecture.svg` — discovery, validation, analogue, imaging and verification layers, with claim boundaries.
2. `figure2_cross_mission_direction.svg` — directional concordance for the failed cross-mission gravity transfer and time-resolved radiation comparisons.
3. `figure3_audit_concordance.svg` — VST- and STAR-count effect concordance with NASA differential-expression results across ten contrasts.
4. `figure4_go_context.svg` — top GO Biological Process terms in the OSD-255 discovery panel and the null subset-enrichment result.
5. `figure5_cell_class_context.svg` — the twelve canonical major-class marker anchors from the Mouse Retina Cell Atlas across four bulk OSDR contrasts, with the non-deconvolution boundary stated in the figure.
6. `figure6_cross_modal_context.svg` — an explicitly unpaired evidence matrix distinguishing study-level photoreceptor convergence, imaging-only apoptosis evidence and unsupported oxidative/vascular cross-modal claims.

The editable source is the versioned figure-generation script; no values are manually inserted into the SVG outputs.
